# visus-quickstart
[Visus](https://github.com/cockroachlabs/visus) is a tool available from [Cockroach Labs](https://cockroachlabs.com/) that allows the creation of custom [Prometheus](https://prometheus.io/) metrics for monitoring Cockroach Database (CRDB). Visus allows custom queries to be created for advanced monitoring of CRDB clusters The purpose of this repository is to get started using Visus quickly, along with some helpful tips and tricks.

## Prerequisites:
As a first step, it's strongly recommended that you setup your Prometheus instance using the [Monitor CockroachDB with Prometheus](https://www.cockroachlabs.com/docs/stable/monitor-cockroachdb-with-prometheus) guide. It will guide you through the setting up of the basic Prometheus integration with CRDB and provide you with some baseline metrics to get started
